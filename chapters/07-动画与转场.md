# 07 · 动画：逐帧 tick 驱动的世界

项目没有声明式动画曲线系统，动画统一由帧调度器的每帧 tick 驱动：转场、惯性滚动、长按计时、常驻轮询，全是同一个 mechanism 的不同用法。

## 7.1 帧调度：beginFrame 的五步

1. **drainUiTasks** — postUi 投递的跨线程任务在帧头执行，任务里的 setState 可在同一帧进入构建和绘制
2. **tickAnimations** — std::function 逐帧动画回调（animation_scheduler.cpp）；惯性 fling、长按 500ms 计时、常驻轮询都复用这个 tick
3. **dirty 时调用 FrameFunc** — requestRender 只置脏标志，真正的构建在 VSync 后
4. **buildFrame 生成 Canvas** — 空闲帧槽中构建并复制纹理脏区；满时延后至下一 VSync
5. **Raster 消费快照** — 上传、录制、提交 Vulkan 命令

> **ℹ️ 合并语义**：多个绘制请求合并到一次 VSync；setState 的同步重建仍未合并。

## 7.2 导航转场：280ms 滑动 + 路由生命周期

Navigator 持有 Route 列表，每条 Route 持有页面 Element 树。push 与 pop 负责：

1. 派发 WillLeave / WillEnter（返回 false 可否决本次导航）；
2. 执行 280 毫秒滑动转场（返回入口：导航栏返回键，或平台壳上报的 BackPressed——Android 返回键/手势、iOS 壳层边缘手势）；
3. 派发 DidLeave / DidEnter；
4. pop 完成后 unmount 并销毁 Route。

**页面导航钩子**

```cpp
Navigator::of(context).push(makeWidget<DetailPage>(42), true);
Navigator::of(context).pop(true);

// State 可按需覆写：
// onWillEnter / onDidEnter / onWillLeave（返回 false 拦截离开）/ onDidLeave
```

> **💡 转场期间的关键性能设计**：转场与滚动的逐帧位移只写偏移（setPosition），不触发布局；滚动 offset、按钮 pressed、导航动画都位于 View 层，不会因 Widget 重建丢失。HomePage 被覆盖时 State 原地保留，onDidEnter 里再 setState 一次即可刷新数据。

## 7.3 动画的四种用法（同一个 tick）

| 用法 | 驱动方式 | 代码位置 |
|---|---|---|
| 转场动画 | NavigationView 每帧写页面偏移 + 裁剪 | navigation_stack.cpp |
| 惯性滚动 fling | 松手初速度 + 每帧摩擦衰减；边界橡皮筋回弹 | view/scroll_control.cpp |
| 长按计时 | 500ms 截止，计时复用动画调度器的每帧 tick | pointer_input.cpp |
| 常驻帧轮询 | startAnimation 回调每帧看 revision，变了才广播 | market_data.cpp:24 |

**常驻轮询：等价于 Flutter setState 的合并语义**

```cpp
evk::ui::startAnimation([source = client, ...](int64_t) mutable {
    if (source->revision() == revision) return false;  // 没变，下帧再看
    current = source->snapshot();                       // 不可变快照，无锁换指针
    evk::ui::EventBus::instance().emit(kEventMarketData);
    return false;   // 常驻，不自我了断
});
// "VSync polls the latest immutable state once.
//  No per-tick UI queue grows."
```

## 7.4 浮层淡出：Widget 级动画

Widget 浮层（overlay.h）支持到期淡出：durationMs 控制停留时长，fadeOutMs 控制淡出时长——背景、文字与子控件的绘制透明度一起降低，不改变布局。显式 close() 与页面销毁仍立即清理。

```cpp
evk::ui::OverlayOptions toast;
toast.placement = evk::ui::OverlayPlacement::Bottom;
toast.offset = evk::ui::safeAreaInsets().bottom + 40;
toast.pointerTransparent = true;
toast.durationMs = 2000;   // 停留 2 秒
toast.fadeOutMs = 240;     // 240 毫秒淡出
customToast = evk::ui::showOverlayWidget(
    evk::ui::sizedBox(400, 80, evk::ui::container(0x1769C2FF)), toast);
```

> **ℹ️ 当前边界**：动画系统是手写 tick + 数值插值的精简集，没有声明式 AnimationController / 曲线库；RepaintBoundary 会随命令重放嵌套边界、SDF 圆角裁剪与阴影参数，转场、滚动导致位置/裁剪变化会重新绘制静态图。
